# 星川内容分析与脚本生成工作台（服务商版）

面向服务商的独立 GitHub Pages 站点，仅保留原星川决策工作台中的「内容分析与脚本生成」板块。

## 功能范围

- 商品信息录入与内容偏好标签
- 爆款素材底池匹配与素材策略一页纸
- 痛买放转四段式带货脚本生成，默认提供 4–5 个方向、至少 4 个
- 脚本优化迭代、复制与飞书导出
- 免登录开放访问，历史记录保存在浏览器本机

## 访问与身份边界

- 站点免登录、免登记，打开即用；首次访问自动写入本机身份「本机用户」，无登录弹窗
- 使用记录与内容历史保存在浏览器本机（localStorage / IndexedDB），不跨设备同步
- 未登记状态下隐藏「引用爆品库商品」入口与真实 AI 镜头生成按钮（`?demo=1` 演示模式仍可体验镜头效果）
- 商品洞察、Brief、策略一页纸、五方向脚本、飞书文档导出等核心链路均无需登录，走服务端应用凭证
- 追加 `?demo=1` 进入演示模式：使用本地预置数据，不发起真实 AI 请求

## 技术栈

React 19、TypeScript、Vite、Tailwind CSS、Framer Motion。生产构建通过 `vite-plugin-singlefile` 将主程序内联为单个 `index.html`，另保留 `xlsx.full.min.js` 作为按需加载资源。

## 本地开发

```bash
npm install
npm run dev
```

## 生产构建

```bash
npm run build
```

构建产物位于 `dist/`，可直接部署到 GitHub Pages。
